# GA_labs

## Лабораторная работа № 1

Генетический алгоритм для минимизации функции Стыблинского—Танга в пространстве размерности 7.

### Требования

- Python 3.10 или новее;
- NumPy;
- Matplotlib.

### Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install numpy matplotlib
```

### Запуск

Из корня проекта:

```powershell
python 1Lab\main.py
```

Программа выполняет 6 конфигураций генетического алгоритма по 20 запусков, сравнивает их со случайным поиском и выводит таблицы результатов в консоль.

### Результаты

После запуска создаются или обновляются:

- `1Lab/Exp.csv` — параметры и результаты 120 запусков, решения, значения целевой функции и истории сходимости;
- `1Lab/Grafics/generations.png` — влияние числа поколений;
- `1Lab/Grafics/population.png` — влияние размера популяции;
- `1Lab/Grafics/ga_vs_random.png` — сравнение ГА и случайного поиска.

Подробное описание алгоритма и анализ экспериментов находятся в `1Lab/Raport.md`.
